# منصة جوميرا التعليمية

## نبذة عن المشروع

منصة "جوميرا" هي منصة تعليمية عربية متكاملة تُقدم خدماتها لطلاب ومعلمين في ثلاث دول: مصر، الإمارات، والكويت. تجمع المنصة بين تقديم الكورسات التعليمية (على غرار Udemy وCoursera) وخدمة الطلبات الخاصة (مشابهة لمنصة مستقل)، مع إشراف كامل من قِبل الأدمن لضمان الجودة والملاءمة.

## الدول المدعومة

- مصر
- الإمارات
- الكويت

لكل دولة نظام تعليمي خاص بها، لذا تُراعي المنصة الفروق في المراحل الدراسية، المواد، والتقسيمات الدراسية لكل دولة.

## الميزات الرئيسية

### تصفح الكورسات
- اختيار الدولة (مصر، الإمارات، الكويت)
- اختيار المرحلة الدراسية (مثلاً: ابتدائي، إعدادي، ثانوي)
- اختيار المادة الدراسية (مثلاً: رياضيات، علوم، لغة عربية)
- اختيار الترم الدراسي (الأول أو الثاني)
- عرض الكورسات المتاحة مع إمكانية مشاهدة التفاصيل والتقييمات والتسجيل

### قسم الطلبات الخاصة
- إمكانية رفع طلب لشرح واجب أو موضوع معين
- تقديم عروض من المعلمين لتلبية الطلبات
- التواصل عبر شات داخلي
- إشراف الأدمن على الطلبات والعروض

### لوحات التحكم
- لوحة الطالب: تصفح الكورسات، رفع الطلبات، متابعة العروض
- لوحة المعلم: رفع كورسات، تقديم عروض، إدارة المحتوى
- لوحة الأدمن: مراجعة واعتماد الكورسات والطلبات، إدارة المستخدمين

### نظام الشات الداخلي
- تواصل مباشر بين الطلاب والمعلمين
- إشعارات فورية
- دعم إرسال الملفات

## تصميم الواجهة
- لغة الواجهة: العربية بالكامل، مع دعم اتجاه النص من اليمين إلى اليسار (RTL)
- تصميم متجاوب يعمل على جميع الأجهزة
- أنيميشن سلس وجذاب لتحسين تجربة المستخدم

## التقنيات المستخدمة
- React.js للواجهة الأمامية
- Node.js للخادم الخلفي
- MongoDB لقاعدة البيانات
- Socket.io لنظام الشات المباشر
- Material-UI مع تخصيص للدعم الكامل للغة العربية
